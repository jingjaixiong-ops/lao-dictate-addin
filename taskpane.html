Lao Speech-to-Text for Word

ตั้งค่า Azure Speech (สำหรับโหมด Real-time)

ต้องใช้ Azure Speech Key + Region (สมัคร/ดู key ได้ที่ Azure Portal → Speech service มี free tier ให้ทดลอง) สำหรับภาษาลาวแนะนำเลือก region ที่ใกล้ เช่น southeastasia

1) ถอดเสียงแบบ Real-time (คำต่อคำ / ประโยคต่อประโยค)

ใช้ Azure Speech SDK เชื่อมต่อผ่าน WebSocket โดยตรง ทำงานได้จริงใน Word desktop (WebView2) พูดแล้วแทรกลงเอกสารทันทีเมื่อจบแต่ละประโยค ต้องมีอินเทอร์เน็ตและตั้งค่า Azure Speech ด้านบนก่อน

ตัวอย่างข้อความสด (คำที่กำลังฟัง + ที่แทรกแล้ว)

2) ถอดเสียงจากไฟล์เสียง (ไม่ real-time)

ใช้เมื่อมีไฟล์เสียงอัดไว้แล้ว หรือรันบน Word for Mac ที่ไม่รองรับ Web Speech API

คีย์นี้จะถูกเก็บไว้ในเครื่องของคุณเท่านั้น (localStorage) และส่งตรงจากเบราว์เซอร์ไปยัง OpenAI สำหรับการใช้งานในองค์กร แนะนำให้เปลี่ยนไปเรียกผ่านเซิร์ฟเวอร์ตัวกลาง (proxy) แทนการฝังคีย์ในไคลเอนต์
